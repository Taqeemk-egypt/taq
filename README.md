# منصة تقييمك (Taqeemk) - Smart Links & Dynamic QR Codes

منصة ويب متكاملة وعالية الأمان تجمع بين مفهوم **Linktree** لإدارة صفحات البايو وروابط الأعمال المصنفة داخل **قوائم منظمة**، مع نظام متقدم لإنشاء وتخصيص وإدارة **أكواد QR الديناميكية** (التي تتيح تغيير الرابط المستهدف بعد الطباعة دون إعادة طباعة الكود) و**أكواد QR الثابتة**.

---

## 🚀 المميزات الرئيسية (Core Features)

1. **صفحات بايو ذكية (Linktree-Style Bio Pages):**
   - تخصيص كامل للاسم، النبذة التعريفية، الصورة/الشعار، وألوان الثيم.
   - شريط حسابات التواصل الاجتماعي (واتساب، إنستغرام، تيك توك، تويتر، فيسبوك، يوتيوب، لينكد إن).
   - تقسيم الروابط إلى **قوائم ومجموعات مصنفة** (مثل: "قنوات التواصل"، "عروض الشهر"، "المنتجات").
   - تتبع فوري للنقرات والإحصائيات لكل رابط.

2. **أكواد QR الديناميكية والثابتة (Dynamic & Static QR Studio):**
   - **أكواد ديناميكية (Dynamic QR):** يتم توليد رابط توجيه مختصر ذكي؛ يمكنك تعديل الرابط النهائي في أي وقت من لوحة التحكم دون إعادة طباعة الكود.
   - **أكواد ثابتة (Static QR):** توليد فوري للروابط أو معلومات الاتصال المباشرة.
   - استوديو تصميم تفاعلي: اختيار ألوان الكود والخلفية، شكل الزوايا والنقاط (Extra-Rounded / Dots / Squares).
   - تصدير فوري عالي الدقة بصيغة PNG أو SVG.

3. **نموذج الاشتراك والدفع (Monetization & Payments):**
   - **رسوم التفعيل لمرة واحدة مدى الحياة:** 100 جنيه مصري فقط.
   - **رقم المحفظة / إنستاباي المستلمة:** `01503773224`.
   - **بوابة رفع إشعار التحويل:** يرفع المستخدم لقطة شاشة للوصل مع رقم الهاتف والمرجع.
   - يظل الحساب معلقاً حتى يتم مراجعته واعتماده من لوحة الإدارة.

4. **حساب الإدارة والتحكم (Admin Roles & Controls):**
   - يتم تعيين حسابات الإدارة بصورة آمنة عبر قاعدة البيانات (`profiles.is_admin = TRUE`).
   - وصول غير محدود ودائم مجاناً مدى الحياة، وتجاوز تلقائي لأي بوابة دفع.
   - لوحة تحكم إدارية خاصة بمراجعة إيصالات التحويل، فحص الصور بتقنية Lightbox، وتفعيل الحسابات بنقرة واحدة.

## 📂 هيكل الملفات (File Structure)

- `index.html`: الصفحة الرئيسية، مولد QR المباشر، باقات التفعيل، ونوافذ تسجيل الدخول والحساب الجديد.
- `dashboard.html`: لوحة تحكم المستخدم (تخصيص البايو، إدارة القوائم، استوديو QR، بوابة التحويل، ومعاينة حية على شاشة هاتف ذكي).
- `admin.html`: لوحة الإدارة لمراجعة إيصالات التحويل والموافقة/الرفض وإدارة المستخدمين.
- `p.html`: صفحة البايو العامة للجمهور (`/p.html?u=username`) مع عدادات النقرات وزر مشاركة الكود.
- `r.html`: محول الروابط لأكواد QR الديناميكية (`/r.html?c=SLUG`) مع تسجيل التحليلات وإعادة التوجيه التلقائي.
- `404.html`: صفحة الخطأ المخصصة مع روابط سريعة للرئيسية ولوحة التحكم.
- `style.css`: أنظمة الألوان، أنماط الزجاج (Glassmorphism)، وتصميم إطار هاتف الآيفون للمعاينة.
- `app.js`: محرك المنصة البرمجي، التحقق الأمني، إدارة الجلسات، توليد QR، وتخزين البيانات.
- `config.js`: إعدادات الربط مع Supabase وبيانات الإدارة والمحافظ.
- `supabase_schema.sql`: كود قواعد البيانات المتكامل لـ Supabase (RLS, Triggers, Storage).

---

## 🛡️ إعداد قاعدة البيانات وأمان Supabase (RLS Setup)

1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
2. افتح **SQL Editor** والصق محتويات الملف `supabase_schema.sql` واضغط **Run**.
3. سينشئ السكربت تلقائياً:
   - جداول `profiles`, `lists`, `links`, `qr_codes`, `qr_scans`, `payments`.
   - سياسات الأمان الصارمة (Row Level Security - RLS).
   - إعداد التخزين `storage.buckets` لإيصالات الدفع `receipts` وصور الحسابات `avatars`.
   - التفعيل التلقائي لصلاحيات الإدارة عبر حقل `is_admin = TRUE`.
4. انسخ رابط المشروع والمفتاح العام من **Project Settings > API** وضعهما في `config.js`:
   ```javascript
   SUPABASE_URL: "https://your-project.supabase.co",
   SUPABASE_ANON_KEY: "your-anon-public-key"
   ```

*ملاحظة: تدعم المنصة وضع التشغيل التجريبي التلقائي (Offline/Demo Mode) عبر التخزين المحلي حتى قبل ربط المفاتيح.*
